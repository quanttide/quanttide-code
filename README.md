# quanttide-code

量潮软件工程

## 简介

quanttide-code 是量潮知识管理体系中的软件工程模块，专注代码工程化实践的标准、方法与工具。

## 功能

- 软件工程标准与规范
- 代码示例与最佳实践
- 工程化工具链集成

## 快速开始

请参考各子模块的 README 文档。
